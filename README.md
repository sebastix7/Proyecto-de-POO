# Proyecto-de-POO

Juego **Tetris** por consola en Java, desarrollado en grupo para el curso de POO.

## Clonar el repositorio

```
git clone https://github.com/sebastix7/Proyecto-de-POO.git
```

## Estructura del proyecto

- `interfaces/`: interfaces (`Rotable`)
- `modelo/`: piezas (`Pieza`, `TipoPieza`, `PiezaI`, `PiezaO`, `PiezaT`, `PiezaS`, `PiezaZ`, `PiezaJ`, `PiezaL`) y tablero
- `logica/`: lógica del juego
- `excepciones/`: excepciones propias
- `Main`: punto de entrada

## Cómo ejecutar

1. Abrir la carpeta del proyecto en VS Code.
2. Ejecutar `Main` (o `PruebaPiezas` para probar solo las piezas).
